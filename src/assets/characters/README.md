# Character pictures

Drop one image per character here and rebuild. It appears on that character's tile and page. Characters without an image show their original drawn portrait from `src/features/characters/Portrait.tsx`.

Name each file after the character id, as `.jpg`, `.png`, `.webp` or `.avif`. Portrait shape works best, about 800 × 1000.
